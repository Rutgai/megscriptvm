megscriptvm JavaScript kütüphanesi

megscript ve MegscriptVM için bağımlılıksız JavaScript araçları: sunucuları koddan yöneten API istemcisi (gerçek zamanlı oyuncu sayısı dahil) ve megscript kodu için tokenlayıcı, renklendirici ve TR/EN çevirici. Tarayıcıda ve Node 18+'da çalışır.

Zero-dependency JavaScript tools for megscript and MegscriptVM: an API client to create, run and watch servers (with a real-time player count) and a tokenizer, syntax highlighter and Turkish/English translator for megscript code. Works in browsers and Node 18+. ES modules, no build step.

Dene / Try it

Soldaki megscript kodunu değiştir; sağda renklendirilmiş hâli görünür. Çeviri düğmeleri tanımlayıcılara ve metinlere dokunmadan yalnız anahtar kelimeleri çevirir. Sonuç, derleyicinin megc --biçimle --dil çıktısıyla aynıdır.

Demo yüklenemedi: sayfa dosyadan (file://) açıldıysa tarayıcı JavaScript modüllerini yüklemez; siteden aç. 

  


  
Kullanım / Usage

  
import { MegscriptVM, renklendir, cevir, tokenla } from "https://megscriptvm.js.org/megscriptvm-js/index.js";

// Yerel MegscriptVM konsolu (http://localhost:8090); "" = aynı köken
const vm = new MegscriptVM({ adres: "http://localhost:8090" });
await vm.olustur({ ad: "lobi", kod, port: 25565, kademe: 2 });

// Gerçek zamanlı oyuncu sayısı: değişince çağrılır (sekmeye dönünce de hemen yenilenir)
const durdur = vm.oyunculariIzle("lobi", ({ sayi, adlar, kaynak }) => {
  console.log(`${sayi} oyuncu (${kaynak})`, adlar);
});

// megscript kodu: renklendir, dile çevir
element.innerHTML = renklendir(kaynak);       // güvenli HTML (kaçışlı)
const ingilizce = cevir(kaynak, "en");        // megc --biçimle --dil=en ile aynı


  
API istemcisi / API client

  

    
YöntemNe yapar

    
new MegscriptVM({ adres, fetch })Konsola bağlanır. adres boşsa aynı köken.

    
ozet()Çalışan / toplam sunucu, toplam bellek, toplam oyuncu, ana makine kademesi, olaylar.

    
sunucular(), sunucu(ad)Sunucu kayıtları: durum, kademe, port, bellek, oyuncular.

    
olustur({ ad, kod, port, kademe, islemci, politika, not, otomatik, baslat })megscript kodundan sunucu kurar (hazır şablon yok).

    
guncelle(ad, ayarlar)Kodu ya da ayarları değiştirir.

    
baslat(ad), yeniden(ad), durdur(ad), sil(ad)Sunucu yaşam döngüsü.

    
otomatik(ad, acik)Bekçi: çökerse yeniden başlatılsın mı.

    
kod(ad), gunluk(ad, n)Kaynak kodu ve son günlük satırları.

    
oyuncular(ad){ sayi, adlar, kaynak, tepe }. kaynak: "sunucu" (gerçek, sistem.oyuncular ile bildirildi) ya da "tahmini".

    
oyunculariIzle(ad, geriCagri, { aralik })Oyuncu listesi değişince bildirir; durduran işlev döner.

  

  
Hatalar MegscriptVMHatasi olarak gelir: durum (HTTP kodu, ağ hatasında 0) ve veri (konsolun yanıtı).


  
Sözdizimi araçları / Syntax tools

  

    
İşlevNe yapar

    
tokenla(kaynak)Kaynağın tamamını kapsayan tokenlar (boşluklar dahil): anahtar, ad, metin (^( … ) ifadeleriyle), sayı, yorum, işleç, öznitelik.

    
renklendir(kaynak, { onek })Güvenli HTML; sınıflar ms-anahtar, ms-metin, ms-yorum …

    
dilBul(kaynak)"tr", "en" ya da null (imza ya da ilk anahtar kelime).

    
cevir(kaynak, "tr" | "en")Dosyayı öbür dile çevirir; derleyicinin megc --biçimle --dil çıktısıyla birebir.

    
standartYazim(tur, dil), ANAHTAR_KELIMELERDerleyicinin anahtar kelime tablosu (kaynağından otomatik üretilir).

  


  
Doğruluk / Correctness

  
Anahtar kelime tablosu derleyicinin kaynağından üretilir ve sınamalarda güncelliği denetlenir. Tokenlayıcı ve çevirici,
    megscript deposundaki her örnek dosyada derleyiciyle karşılaştırılarak sınanır.
